# ملحق تصميم: واجهة إنجليزية + كونسول لحظي + إعدادات السجلات

التاريخ: 2026-11-21 — هدف صريح من المستخدم.

## النية
جعل التطبيق إنجليزياً بالكامل، وإضافة شاشة كونسول تعرض تشغيل الـ Run لحظياً، وإعدادات تسمح بحذف/تنظيف السجلات ونسخها، مع نسخ لوق الكونسول أيضاً.

## القرارات
- **اللغة**: كل النصوص الظاهرة للمستخدم داخل الهدف (`SandboxLabApp`) و`ProbeCategory.displayName` في Core تصبح إنجليزية. ملفات README/الوثائق ليست جزءاً من التطبيق.
- **الكونسول**: `ConsoleStore` (`@MainActor`, `ObservableObject`) يحفظ أسطراً (`id`, `timestamp`, `text`) ويعرضها `ConsoleView` بخط monospaced. يُسجَّل قبل كل تشغيل، وبعد كل نتيجة (النص الخام)، وعند الخطأ — فيظهر التحديث لحظياً أثناء `Task`. زران: Copy Log وClear.
- **الإعدادات**: `SettingsView` فيها Clear All Logs (تأكيد destructive) وCopy Logs. تُنسخ النصوص عبر `UIPasteboard.general.string`.
- **التخزين**: إضافة `deleteAll()` إلى `ProbeStoring` و`InMemoryProbeStore` و`SwiftDataStore`، مع اختبار وحدة يغطي الحذف (الإجمالي 11 اختباراً).
- **التوصيل**: `ProbeListView` يستقبل `ConsoleStore` ويعرض روابط Console وSettings وLog في الـ toolbar.
- لا تغيير في منطق البناء/الريليز أو في كود الحالة التجريبية.

## معايير القبول
- لا توجد سلاسل عربية في ملفات Swift داخل التطبيق/Core (باستثناء التعليقات إن وُجدت؛ يُفضَّل إزالتها).
- الكونسول يُظهر سطر "Running ..." قبل التنفيذ ونتيجة الـ Run بعده مباشرة.
- Clear All Logs يُفرغ SwiftData؛ Copy Logs وCopy Console Log يضعان نصاً في الحافظة.
- `swift test` → 11/11، وCI أخضر، والريليز 0.0.0 يُستبدل كما هو.
